The 24×24 Contract

Every icon in the app — whether it comes from Lucide, Material Symbols, or your own hand — is merged into one build artifact. Vendor icons arrive uniform. Yours will not. This is the agreement between whoever draws the SVG and the pipeline that consumes it.

Handled automatically

01What the preprocessor absorbs

You do not have to hand-clean exports. Every SVG entering app/assets/icons/ passes through normalisation before it reaches any emitter. These problems are solved, silently, on every build.

Editor chrome is stripped sodipodi · inkscape · metadata

Namespaced editor state, RDF metadata blocks, XML declarations, DOCTYPEs, comments, and empty <defs> are removed entirely. An Inkscape file carrying window geometry and zoom level loses all of it.

- <sodipodi:namedview inkscape:zoom="0.19" inkscape:window-x="236" …/>
- <metadata id="metadata1"><rdf:RDF>…</rdf:RDF></metadata>
- <defs id="defs1" />

Every id is namespaced the collision fix

Ids are rewritten to <slug>__<id>, and every internal reference is rewritten with them — url(#…) in fills and strokes, href, clip-path, mask, filter. This is what makes generic sequential ids safe to merge.

- <linearGradient id="path1">   fill="url(#path1)"
+ <linearGradient id="logo__path1">   fill="url(#logo__path1)"

Without this, two icons both defining path1 collapse into one definition and the second silently wins. With 34 of 40 files sharing layer1, collision is the default outcome, not the edge case.

viewBox is rescaled to the common box

Any source box is fitted into the target, centred, aspect preserved, via a wrapping transform. Absolute width/height attributes are dropped so the icon scales with its container instead of pinning itself to 1024px.

This matters beyond your own files: Lucide and Material are both 24, but fa6-solid is 512 with per-icon overrides to 576, and bi declares no width at all. The pipeline cannot assume a number.

Colour is folded to currentColor

Single-colour icons get their fills and strokes rewritten so they inherit CSS color like text. Icons declared multicolor: true in the manifest keep their palette untouched.

Unsafe content is removed

<script>, all on* event handlers, <foreignObject>, and any external reference are dropped. An SVG from a designer is untrusted markup that you are about to inline into your DOM — an inlined handler in a sprite <symbol> executes.

Your job when drawing

02What the pipeline can't decide for you

Normalisation fixes structure. It cannot fix judgement. These are geometry and composition choices that have to be right in the source file.

Draw on a 24×24 grid, snapped to whole pixels

Set the document to 24×24 units and align edges to integers (half-integers for 1px-wide strokes). Rescaling from 270.93 to 24 is arithmetic the pipeline will do, but coordinates that were never on a grid stay off-grid afterwards, and land blurry at 16px.

Leave a 1–2 unit margin inside the box

Artwork should occupy roughly the middle 20–22 units. Icons drawn edge-to-edge appear oversized beside vendor icons that respect the same padding, and the mismatch is obvious in a toolbar.

Match the stroke weight you're sitting next to

Lucide is 2 units at 24 with round caps and round joins. A first-party icon at 1.5 or 3 reads as a different family even when the shapes are right.

Outline your strokes if the icon goes in a font required, not optional

Save the artwork as filled contours rather than stroked centrelines. Nothing downstream can do this losslessly, so a stroked first-party icon in a font target stops the build by name rather than shipping a blob. The sprite renders strokes natively and does not care.

Union overlapping shapes; avoid self-intersection

Merge overlapping subpaths into one contour before saving (Path → Union). Fonts fill by non-zero winding, so overlaps and reversed contour directions turn holes solid — the classic icon-font artifact.

Flatten transforms into coordinates

Nested transform= chains survive normalisation but compound with the fitting transform and make debugging geometry miserable. In Inkscape: Preferences → Behaviour → Transforms → Store transformation: Optimized.

Name the file as the slug

The filename is the identifier. empty-box.svg resolves as local/empty-box. Lowercase, hyphens, no spaces, no version suffixes — logo-final-v3.svg becomes an icon literally named logo-final-v3.

No preprocessing can save these

03Hard failures

Four things are not cleanup problems. They are properties of the output format, and the only fix is upstream in the drawing.

Live <text> elements

Text renders with whatever font the viewer's machine has, or nothing. It cannot become a glyph outline at all. Convert every text object to paths before saving — Path → Object to Path in Inkscape, Type → Create Outlines in Illustrator, Outline text on Figma export.

A real file in your projects is 1782 bytes whose entire artwork is one <text> node at font-size:238.845px. It will render differently on every machine that opens it.

Embedded raster <image> data

A base64 PNG inside an SVG defeats the entire point: it does not scale, it cannot be a glyph, and it inflates the sprite by orders of magnitude. Redraw as vector or keep it out of the icon set.

Multiple colours, in a font target

A TrueType glyph stores no colour — it is filled contours, coloured at render time by CSS color. Two-tone is unrepresentable, not merely difficult. Multicolour icons ride in the sprite and are skipped by the font emitter, which reports each one it dropped.

Filters, blurs, and blend modes

<filter> effects do not survive font conversion and are expensive to rasterise in a sprite. Bake the effect into geometry or drop it.

The stroke trap, specifically. A stroked path with fill="none" does not fail loudly in a font — it fills the centreline as a solid region and produces a blob that looks nothing like the icon.

Strokes are not expanded for you. Both published JavaScript expanders run the artwork through potrace: they rasterise, re-trace, and hand back rounded corners and wobbling stems. Rather than ship geometry that quietly stopped matching the sprite, the build refuses and names the icon.

Vendor sets are handled — where a provider publishes its own font, outlines are lifted from there, already expanded and tuned by the people who drew them. For your icons there is no such source, so outlining is your job: Path → Stroke to Path in Inkscape, Object → Path → Outline Stroke in Illustrator, Outline stroke in Figma.

04Export settings

Getting these right removes most of the cleanup before it starts, and makes diffs on icon files readable.

ToolDo thisNot this
Inkscape File → Save As → Optimized SVG, with Remove metadata, Remove comments, and Remove unused defs checked; 3 decimal places Inkscape SVG — keeps sodipodi:, inkscape:, layer state, window geometry
Illustrator Export As → SVG, Styling: Presentation Attributes, Object IDs: Minimal, Decimals 2, Responsive off Styling: Internal CSS — emits a <style> block whose class names collide exactly like ids do
Figma Frame at 24×24, Export → SVG with Outline text on and Include "id" attribute off Exporting a nested component — brings the wrapper frame in as an extra clip path

05Before you commit the file

Run this once per icon. It takes under a minute and prevents every failure documented above.

  1. Document is 24×24 — and the artwork sits inside the middle 20–22 units.
  2. All text converted to paths — no <text> or <tspan> anywhere in the file.
  3. No embedded images — search the file for <image and for base64.
  4. Overlapping shapes unioned — one contour per visual region.
  5. Single colour is pure black — unless the icon is genuinely multicolour, in which case flag it in the manifest.
  6. Saved as Optimized / Plain SVG — not the editor's native format.
  7. Filename is the slug — lowercase, hyphenated, final.
  8. Rendered at 16px — if it turns to mud, the coordinates are off-grid.

You do not have to be perfect. Items 1–8 make the output better and the diffs smaller, but the preprocessor is the safety net — a raw Inkscape export with layer1, a 270.93 viewBox, and editor metadata still builds correctly. Only section 03 contains things it genuinely cannot rescue.
